# Townlight Station recorder status

As of November 20, 2026, this repository maintains the Python recorder and its
TypeScript operator UI in beta-1/. Meetings and Records integration exists, but
service/media/database configuration remains separate.

The released MSI contains the Python package, not the former Rust engine.
Acceptance is candidate-specific and scoped; it does not establish automatic
recorder setup or every installed workflow.

Rust source, its inherited assessment and failures are preserved in the private
scottconverse/civiccast-lab repository. See
[the separation record](docs/RUST-SEPARATION.md).
