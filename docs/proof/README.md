# Proof-record interpretation

Files in this directory are immutable historical records for specific source commits and installed
candidates. They must be read with their recorded candidate identity and must never be combined
across commits to manufacture an all-up result.

Some records created before 2026-08-29 refer to one-station-week and three-station-week acceptance
gates. That wording is superseded and is not the current product requirement. The current narrow beta
gate is one exact installer on a fresh Windows machine completing operator bootstrap/configuration,
real media ingest and scheduled program-on-air operation, caption verification, service restart and
recovery, and an uninterrupted four-to-eight-hour soak. Passing that narrow gate does not establish
complete S1-S26 functional parity or production-headend acceptance.
