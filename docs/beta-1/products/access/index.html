The bounded staff workflow

  1. Save and reopen an accessibility review with its actual source, findings and saved model advice.
  2. Retain plain-language or translation drafts with source/output, language, model, staff actor and review status.
  3. Export the complete Markdown record with verified bytes; attach the actual file through Records when authorized.

The Windows local-model workflow differs from the standalone service, whose language samples are explicitly not translations of the input. Human review remains required. Access does not certify ADA compliance or publish text.
