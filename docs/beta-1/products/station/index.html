Inside the workflow

What Station supports

Connect the meeting context

Use the Meetings catalog to associate proceedings with their recording.

Preserve the canonical media

Hand a private recording to Records with a verifiable identity.

Configure delivery separately

Station includes paths for configured CivicCast SRT coverage and staff-approved completed YouTube uploads.

Evaluate locally

Start with one real workflow.

Follow Townlight first run to provision Station. On an existing installation, use Settings → Modules → Townlight Station → Set up meeting recording.

Scope of this beta

Windows 1.9.1.1 passed camera and microphone preview, recording, and playback on a Logitech C920. Earlier signed acceptance covers synthetic live recording and a verified Records transfer over 2 GiB. Test your own inputs before a meeting. External delivery requires separate configuration.
