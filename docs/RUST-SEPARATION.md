# Rust implementation separated from Townlight Station

On November 20, 2026, Scott directed the experimental Rust broadcast engine into
private `scottconverse/civiccast-lab`.

The complete history, branches and tags were copied and verified before removing
the Rust workspace, web operator, installer, harnesses and engineering scripts
from this repository's current tree. Original snapshot:
`85774af3505ac9947e10d7b5e484ed25293ef671`.

Dated proofs, historical commits, tags and release evidence retain their original
identities. No beta-1/ file was changed. The Python meeting recorder, TypeScript
operator UI, pinned CivicCast source, documentation and Meetings/Records wiring
remain. Current root documentation now describes that recorder.

This does not fix the recorder's setup or usability gaps, change component
versions, or replace the released Windows MSI or its frozen source pins. That MSI
never contained the Rust engine. No new installed acceptance is claimed here.
Rust issue #29 belongs to Lab, not the recorder or its release gates. No Mac port
is included.
